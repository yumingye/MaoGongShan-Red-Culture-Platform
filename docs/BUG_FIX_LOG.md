## BUG-001 核心页面中文乱码

- 影响页面：首页、毛公山概览、红色历史、全景图库、数字资源库、实践调研、山软青年、地图导览。
- 原因：部分文件历史写入时发生编码污染。
- 修复方式：重写受影响 Vue 文件，统一使用 UTF-8 中文文案。
- 验证结果：源码乱码扫描通过，生产构建通过。

## BUG-002 二级专题页面不足

- 影响页面：概览、历史、调研、山软、地图、图库、资源库。
- 原因：原项目以一级页面和列表页为主，多级路由承接不足。
- 修复方式：新增 `topicPages.js` 和 `TopicDetail.vue`，扩展 25 个专题页。
- 验证结果：新增专题路由纳入 `npm run check` 抽查并通过。

## BUG-003 专题图片路径不存在

- 影响页面：山软青年专题、青年责任专题、调研感悟专题、山软青年图集。
- 原因：引用了截断后的图片文件名。
- 修复方式：改用实际存在的 `20240730-qingdao-campus-of-shandong-university-01-jpg.jpg`。
- 验证结果：专题图片路径检查通过。

## BUG-004 质量检查脚本乱码

- 修复方式：重写 `frontend/scripts/quality-check.mjs`。
- 验证结果：`npm run lint`、`npm run test`、`npm run check` 均通过。

## BUG-005 地图页无 Key 状态展示不稳定

## BUG-006 首页专题入口不可读

- 影响页面：`/`。
- 原因：首页文案乱码，按钮文字不可读。
- 修复方式：重写首页首屏、概览、统计、精选历史、图库、资源分类、实践项目和导览入口。
- 验证结果：首页返回 200，生产构建通过。

## BUG-007 文档乱码

- 修复方式：重写核心文档。

## BUG-008 视频资料统计为 0

- 影响位置：`/api/stats`、首页或后台统计展示。
- 原因：资源库中缺少 `视频资料` 类型记录。
- 修复方式：新增 `backend/augment_video_resources.py`，以 UTF-8 脚本方式补充 8 条视频资料入口，并清理 PowerShell 管道造成的问号脏数据。

## BUG-009 全景图库存在外链图片导致潜在空图

- 影响页面：`/scenery`、`/images/:id`。
- 原因：`images` 表中有 66 条外链图片记录，外部站点握手超时或拒绝访问时会出现加载失败。
- 修复方式：新增 `backend/localize_gallery_images.py`，将 66 条外链展示路径替换为项目内真实本地图片，同时保留来源信息；新增 `SafeImage.vue` 作为图库统一图片组件。
- 验证结果：图库 125 条记录外链数为 0，本地路径缺失为 0，经前端服务逐张访问失败为 0。
# 2026-07-22 新增修复

## BUG-010 前端服务未运行

- 影响：首页与全部前端路由。
- 原因：5173 端口没有 Vite 服务；沙箱内 esbuild 无法读取配置目录。
- 修复：使用项目现有依赖在允许环境启动 Vite，并实测页面状态码。
- 验证：首页与新增路由返回 200。

## BUG-011 搜索建议类型错误

- 影响：全站搜索实时建议。
- 原因：后端返回 `{ items: [] }`，前端直接调用 `res.data.slice()`。
- 修复：兼容对象与数组响应，并增加党史学习结果分类。
- 验证：质量检查和浏览器运行检查通过。

## BUG-012 问答专题区分度不足

- 影响：党史事件、精神谱系问题。
- 原因：只对“精神”等宽泛词计分，专名没有标题权重。
- 修复：增加 30 余个领域专名、标题高权重和零命中不回退规则。
- 验证：五四运动、南昌起义、遵义会议、延安精神、科学家精神命中不同来源。

## BUG-013 移动端潜在横向溢出

- 影响：首页窄屏与移动导航。
- 原因：页头局部 `min-width` 覆盖全局移动规则，首屏 Grid 受超大标题最小内容宽度影响。
- 修复：页头使用可收缩 flex，首屏 Grid 使用 `minmax(0,1fr)`，标题允许中文换行。
- 验证：CDP 强制 390px 视口检查无横向溢出，移动菜单可见。

## BUG-014 专题图片露出备用背景

- 影响：党史学习精选大图。
- 原因：图片高度百分比依赖未确定父级高度。
- 修复：安全图片内部 `<img>` 改为绝对铺满容器。
- 验证：浏览器截图显示完整单层图片，失败图片检测为 0。

## BUG-015 通用详情运行时异常

- 影响：红色故事和地点详情。
- 原因：`StructuredDetail.vue` 模板调用 `assetUrl`，脚本未导入该方法。
- 修复：补回结构化导入，并增加接口请求失败的页面内提示。
- 验证：三种视口实际访问故事、地点详情均无运行时错误。

## BUG-016 浏览器测试写死无效人物 ID

- 影响：自动化检查误报人物详情 404。
- 原因：数据库人物主键并非从 1 开始。
- 修复：测试启动时先从 API 获取有效人物、故事、地点和图片 ID。
- 验证：扩展浏览器检查 63 个页面场景全部通过。

## BUG-017 旧页面媒体失败逻辑分散

- 影响：人物、事件、概览、实践、音频、搜索、沙盘和地图。
- 修复：统一改用 `SafeImage`，集中处理加载、备用图和二次失败隐藏。
- 验证：125 条图库记录与浏览器图片自然尺寸检查均通过。

## BUG-018 媒体请求无限等待

- 影响：弱网下的图片和视频区域。
- 原因：旧组件只监听浏览器错误事件，没有超时。
- 修复：图片、视频分别增加 12 秒和 15 秒超时，并统一显示本地备用内容和重试入口。
- 验证：浏览器强制坏图后裂图数为 0。

## BUG-019 异步路由缓存失效可能白屏

- 原因：部署新版本后旧页面可能引用已变更的代码块文件名。
- 修复：路由错误钩子识别代码块加载失败并仅刷新一次，避免刷新循环。
- 验证：生产构建与全部深层路由通过。

## BUG-020 地图筛选能力不足

- 修复：增加名称、地址、描述检索，结果计数、空结果重置和接口失败局部提示。
- 验证：地图搜索真实交互通过。

## BUG-021 浏览器测试执行上下文竞争

- 原因：Vite 热更新时采样表达式偶发返回 `undefined`。
- 修复：指标读取增加四次短间隔重试，失败时记录具体视口和路由。
- 验证：125 个页面视口组合全部完成。

## BUG-022 移动菜单测试假阴性

- 原因：点击与 Vue 下一帧渲染在同一表达式内断言。
- 修复：拆分点击、等待与状态断言，并同步检查横向溢出。
- 验证：移动菜单 `aria-expanded`、可见性和页面宽度均正常。

## BUG-023 手机首屏对比度不足

- 原因：窄屏背景取景集中在亮天空区域。
- 修复：增加独立暗色蒙版、调整移动取景和底部渐隐高度。
- 验证：390×844 最终截图文字清晰，标题完整换行。

## BUG-024 访问统计可能影响业务响应

- 原因：SQLite 短暂锁定时中间件写入异常会覆盖原有成功响应。
- 修复：统计写入独立捕获数据库异常，核心 API 不受影响。
- 验证：全量详情接口和健康检查通过。

## BUG-025 党史专题封面语义错配

- 影响：党史文章、红色事件、红色精神、时间轴。
- 原因：`augment_red_learning.py` 使用 `IMAGES[index % len(IMAGES)]`，把毛公山山景、山东大学校园和不同纪念设施循环分配给无关专题。
- 修复：新增 `learning_media` 章节媒体表与幂等同步脚本；真实照片仅按人工目录关联，其余使用专题独有项目自制信息图。
- 验证：53 篇文章、65 条章节媒体通过语义规则与文件存在检查。

## BUG-026 图文微课画面与标题不对应

- 影响：红色影像馆、12 个视频详情页。
- 原因：视频帧同样按公共 `covers` 数组轮换。
- 修复：为每个微课显式配置 `frames`、`frameTypes`、`frameCaptions`，播放器同步显示当前画面类型。
- 验证：12 个微课均为3幅唯一画面，图片、说明和类型数量一致。

## BUG-027 人物页使用非人物图片

- 影响：人物列表与人物详情。
- 原因：旧扩充脚本将案例卡和团队岗位写入 `historical_figures`，并使用山景作为人物照片。
- 修复：清理非人物记录；四位人物使用已核对公开照片，其余人物使用明确声明“不是本人照片”的项目自制档案图解。
- 验证：30 份人物档案全部存在媒体、说明、来源与版权字段。

## BUG-028 异步页面切换偶发白屏

- 影响：首页连续进入多个深层页面时，主区域偶发保持透明。
- 原因：路由 `out-in` 转场在连续导航和异步组件加载竞争时没有正常结束。
- 修复：移除阻塞整页渲染的转场包装，保留页面内部滚动、轮播和卡片动画。
- 验证：5 种视口、34 条核心路由和 84 条页面生成链接连续访问通过。

## BUG-029 后端断开时首访页面内容不足

- 影响：项目介绍、实践计划、成果、山软专题、来源和讲解页。
- 原因：页面只依赖接口返回，浏览器没有成功缓存时无法形成完整首屏。
- 修复：增加不含敏感信息的公开本地降级数据，并为请求增加超时、一次重试和成功缓存。
- 验证：清空 `sessionStorage`、屏蔽全部 `/api/*` 后，首页、项目、山软专题和讲解页均保持可读。

## BUG-030 图片失败兜底缺少内容分类

- 影响：风景、党史、调研、团队、人物和新闻页面。
- 原因：统一备用图在不同栏目中语义不合适，第二级失败状态也不够明确。
- 修复：`SafeImage` 增加 `kind` 分类、加载超时、自动备用图、重试按钮和最终图文状态。
- 验证：自动注入不存在图片后，页面裂图数为 0。

## BUG-031 地图弹窗拼接未过滤字段

- 影响：地图导览点位弹窗。
- 原因：接口字段直接拼接为 HTML 字符串，异常文本可能造成结构污染。
- 修复：使用 DOM API 和 `textContent` 构造弹窗，图片加载失败切换本地风景备用图。
- 验证：地图分类、搜索、列表联动及弹窗交互通过。

## BUG-032 受限环境复制链接失败

- 影响：事件、图片、调研、专题和资源详情。
- 原因：仅调用 `navigator.clipboard`，未处理权限拒绝和非安全上下文。
- 修复：新增统一复制工具，Clipboard API 失败时自动使用隐藏文本框。
- 验证：生产构建通过，详情页无未处理 Promise。

## BUG-033 情景化访谈缺少显著真实性边界

- 影响：实践访谈专题、访谈详情和问答知识库。
- 原因：原页面只说明隐私处理，没有明确区分创作整理稿与真实受访者原话。
- 修复：专题与详情页增加不可关闭的内容性质提示；知识文档写入“情景化整理稿”考证状态；新增自动校验脚本。
- 验证：4 条访谈稿均具有来源说明和真实性状态，数据库、接口与页面一致。

## BUG-034 浏览器快速检查错误跳过多视口

- 影响：传入多个 `BROWSER_VIEWPORT` 时的自动化结果可信度。
- 原因：快速模式把逗号分隔的视口名称当作一个名称匹配，最终得到空数组。
- 修复：显式视口列表优先于快速模式默认值。
- 验证：桌面端与手机端共 2 种视口实际运行，专题页和详情页无溢出。

## BUG-035 异步路由内容存在但保持透明

- 影响：问答、人物详情等懒加载页面在特定加载顺序下看似白屏。
- 原因：进入动画依赖 `IntersectionObserver`，异步新增节点偶发未及时收到可见回调。
- 修复：每个进入动画节点保留观察器效果，同时增加 900 毫秒强制显现保险；组件卸载时清理计时器。
- 验证：修复前手机问答页主内容长度为 0；修复后手机 12 条路由和桌面 20 条路由连续访问通过。

## BUG-036 问答推荐问题接口失败产生未处理异常

- 影响：后端未启动时，问答页推荐问题可能为空并触发全局异常提示。
- 原因：`onMounted` 直接等待接口，没有局部 `try/catch` 和本地问题集。
- 修复：内置 6 个高频问题，接口成功时替换，失败时继续使用本地问题。
- 验证：断后端状态下页面可读、推荐问题可点击，未出现运行时警报。

## BUG-037 中文短问法未命中已存在知识

- 影响：“平台有哪些功能”“平台怎样避免编造历史信息”。
- 原因：中文短句没有空格，原检索词表也缺少“功能”“编造历史”等语义词组。
- 修复：补充平台使用、媒体失败、真实性和访谈相关词组，并建立 20 问自动回归。
- 验证：20 个问题全部返回不少于 80 字的有来源回答，形成 17 个不同答案。

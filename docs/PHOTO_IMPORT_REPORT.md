## 文件命名和尺寸

网页文件使用英文小写短横线命名，输出到：

```text
assets/images/
├─ architecture/
├─ banners/
├─ people/
├─ red-culture/
├─ research/
├─ scenery/
└─ team/
```

每张接入照片生成：

- `*-detail.webp`：详情页大图，最长边不超过 2200 像素；
- `*-thumb.webp`：卡片和瀑布流缩略图，最长边不超过 760 像素；
- `*-mobile.webp`：移动端版本，最大 1080×1440；
- `*-hero.webp`：仅 5 张精选横向照片生成，固定 1920×960。

所有版本均先执行 EXIF 方向校正。普通图片保持原始比例，不通过拉伸改变画面。

# 当前限制说明

以下限制来自第三方服务、公开资料授权或现实核验条件，不影响本地演示运行。

1. 高德地图需要用户自行申请 Web JS API Key，并在 `frontend/.env` 中配置 `VITE_AMAP_KEY` 与 `VITE_AMAP_SECURITY_CODE`。未配置时系统使用本地静态地图降级方案。
2. 大模型问答接口为可选配置。未配置 `LLM_API_KEY` 时，系统使用本地检索式问答，不会编造超出资源库的内容。
3. 部分毛公山历史资料需要后续由权威单位进一步核验。平台用来源字段和考证状态区分公开资料、实践团队整理和扩展参考资源。
4. 图片版权以来源页面和来源单位说明为准。本项目用于学习、答辩和社会实践展示，商业传播前应另行确认授权。
5. 当前音频讲解优先使用浏览器语音合成和讲解稿。若需要真人录音，可按 README 的音频目录说明替换。
6. 部分地图坐标为公开资料和项目整理形成的示意坐标，正式导览发布前应人工复核。

当前项目已经具备前后端启动、页面访问、搜索、问答、地图降级、图库、资源库、详情页和质量检查能力。

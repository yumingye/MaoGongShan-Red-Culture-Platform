# 数据来源说明

平台数据分为三类：

1. 毛公山核心资源：围绕毛公山位置、风光、路线、文化叙事和景区公开信息整理。
2. 扩展参考资源：围绕青岛城阳、青岛红色文化、山东红色文化、山东大学和软件学院实践内容整理。
3. 项目实践资料：来自“山软寻脉·毛公山数字调研实践团”的公开项目介绍、实践计划、成果设计、团队分工和技术文档。

## 真实性原则

- 可确认资料保留来源名称、来源链接和考证状态。
- 无法确认的内容不编造具体人物、日期、战斗或功绩。
- 项目计划、实践日志、文化解读和技术说明不等同于历史事实。
- 涉及个人敏感信息时不入库、不前台展示、不写入 README。

## 文档导入原则

本地私有项目申报材料中适合公开的团队名称、所属单位、课题名称、实践主题、建设背景、实践计划和成果规划可以进入平台；身份证号、手机号、私人邮箱、家庭住址和本机绝对路径等个人敏感信息不得进入公开数据库或仓库。

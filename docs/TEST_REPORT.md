## 本轮发现并修复的问题

1. 原照片没有统一命名、尺寸和网页格式。
   通过可重复导入脚本生成英文文件名和三种响应式 WebP 版本。
2. 原照片没有统一前端清单和数据库来源记录。
   新增双端 JSON 清单、数据库字段和稳定 slug 接口。
3. 图库依赖后端时，后端暂时不可用会影响新照片展示。
   加入本地清单降级，后端异常时仍可浏览 42 张项目照片。
4. 图片详情使用数字 ID，数据库重建后链接可能变化。
   新增 `/photos/:slug` 和 `/api/images/slug/{slug}`。
5. 浏览器连续切换深层路由时，Vue `out-in` 转场偶发停留在
   `opacity: 0`，可能导致白屏。
   已移除会阻塞整页渲染的转场包装；滚动入场、轮播和卡片动画继续保留。
6. 旧图库检查脚本不能识别 WebP 尺寸。
   已增加 VP8、VP8X 和 VP8L 解析。
